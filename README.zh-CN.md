# Subtitle Studio

[English](README.md) | 简体中文

把视频里的声音变成可编辑的字幕，再导出成带透明字幕层的叠加视频或字幕文件。

![Subtitle Studio](docs/screenshot.png)

## 能做什么

- 打开常见的视频、音频文件，自动列出里面的每条音轨。
- 用本地模型或云端服务做语音识别。
- 在软件里直接改错字、调时间轴。
- 在棋盘格背景上实时预览字幕效果，边调样式边看。
- 只播放你勾选的音轨。
- 导出可直接使用的字幕文件，或带透明字幕层的视频。

## 下载与安装

发布页提供四种包：

| 包 | 说明 |
|---|---|
| `SubtitleStudio-Setup-x.y.z.exe` | 推荐。安装后自带本地模型和播放、导出所需组件，装完即用。 |
| `SubtitleStudio-Slim-Setup-x.y.z.exe` | 体积更小的安装包。需要 .NET 10 桌面运行时。 |
| `SubtitleStudio-full.zip` | 免安装完整版。解压后双击 `SubtitleStudio.exe`，不需要安装。 |
| `SubtitleStudio-slim.zip` | 免安装精简版。需要 .NET 10 桌面运行时。 |

- 支持 Windows 10 / 11 64 位。
- 安装程序默认只给当前用户安装，不需要管理员权限。会创建开始菜单快捷方式，桌面图标可选；卸载在「设置 → 应用」里进行。
- 卸载不会删除你的设置和导入的字体。
- 安装包没有代码签名，首次运行时 SmartScreen 可能提示风险，点「更多信息 → 仍要运行」即可。
- 精简版需要先安装 [.NET 10 桌面运行时](https://dotnet.microsoft.com/download/dotnet/10.0)。所有发行包都已附带 ffmpeg。

## 快速上手

1. 打开软件，点「打开文件」，或把视频拖进窗口。
2. 时间轴上会出现每条音轨，勾选你要处理的轨道。
3. 在标题栏选好识别模型，点「开始识别」。
4. 在左侧字幕列表里改字，在时间轴上拖动字幕块调整时间。
5. 在样式条里调字体、颜色、描边和位置，直到预览满意。
6. 导出字幕文件或透明叠加视频。

## 界面

窗口分成四块：

- **字幕列表**：每条字幕一行，可以直接修改文字。
- **时间轴**：每条音轨一行，显示波形和字幕块；点哪一行就切到哪条音轨。
- **样式条**：字体、字号、字色、描边和底部边距。
- **预览**：字幕显示在棋盘格背景上，棋盘格表示透明区域。

拖动面板标题可以换位置或停靠，拖动分隔条可以调整大小，布局会被记住。拖乱了就点底栏的「重置布局」，一键回到默认排布。

底栏还会显示文件名、语言菜单和当前状态。

## 多音轨

一个视频里可能有多条音轨，每条都有自己的时间轴行和一套字幕。

- 勾选音轨旁边的复选框，这条轨道才会参与识别和导出；没勾的会被跳过，原有字幕保留。
- 点击某条音轨的行，左侧字幕、下方预览和波形都会切到这条轨道。
- 鼠标移到某条音轨上，右侧会出现两个小按钮：导出这条轨道的音频，或删除整条音轨（删除前会确认）。

识别会按音轨依次进行，状态栏会显示已完成的轨道数和字幕数。

## 语音识别

### 本地模型

下载好模型后，本地识别可以完全离线使用。打开「设置 → 本地模型」，可以下载模型、继续没下完的下载、停止下载或删除模型。程序重启后，没下完的下载会接着进行。

标题栏的模型菜单会列出已经可以使用的本地模型，也会给出常见模型的体积说明、下载链接，以及打开模型文件夹的入口。

### 云端服务

填好 API Key 后可以使用硅基流动和天翼星辰。在「设置」里选中对应服务，点「连接测试」，软件会告诉你 Key 是否可用、有哪些模型可用。

也可以添加自己的 OpenAI 兼容语音识别服务：填写名称、接口地址、API Key 和模型名，它就会出现在模型菜单里。自己添加的服务可以删除，内置的三家不能删除。

### 开始与停止

- 导入文件后不会自动识别。勾好音轨，点「开始识别」才会开始。
- 识别期间，标题栏右侧会显示圆环进度和百分比；点旁边的 **✕** 可以停止。
- 已经识别完的音轨会保留字幕，停止只会结束当前这条轨道。
- 完整跑完一轮后，按钮会变成「重新识别」。

### 识别前降噪

「识别前降噪」默认开启。它会在识别前去掉低频轰声和背景噪声，嘈杂素材的识别结果通常会更好；干净素材基本不受影响。

## 编辑字幕

### 字幕列表

每行显示这条字幕的中点时间和一个输入框。修改文字后，预览和时间轴会立刻更新。

面板右上角的「清空」会删除当前音轨的全部字幕，删除前会确认。

### 时间轴

- **跳转**：在时间轴空白处点击或拖动，播放位置会立刻跟过去，播放中也可以这样跳。
- **移动字幕**：拖动字幕块中间，整块移动。
- **改变时长**：拖动字幕块的左边或右边边缘。
- 字幕块会停在相邻字幕旁边，不会互相重叠。
- **新增和删除**：在字幕条空白处右键，可以在点击位置新增一条字幕；在字幕块上右键可以删除它。新字幕默认 2 秒长，并会自动避开相邻字幕。
- **同一时间只显示一个菜单**：换位置再右键会先关掉旧菜单，左键点时间轴也会关掉。
- **缩放和滚动**：滚轮横向滚动，Ctrl+滚轮以鼠标位置为中心缩放，中键拖动或 Alt+左键拖动平移；标题栏的 `−` / `+` 也能缩放。
- **自适应高度**：音轨行会随面板高度变高或变矮。

## 播放

点「播放」会播放勾选音轨的声音，播放头跟着音频走；再点一下暂停。

没有勾选任何音轨时不会开始播放，状态栏会提示先勾选一条。播放中改变勾选或删除音轨会停止播放，下次播放时按新的勾选重新准备。

播放只用于预览。超长素材的预览只处理前 30 分钟；导出不受这个限制。

## 样式与预览

样式条控制字体、字号、文字颜色、描边和距底部的距离。

- **字体**：字体菜单列出系统字体，最后一项是「导入其他字体…」，支持 `.ttf`、`.otf`、`.ttc`。导入的字体会复制到用户目录，重启后仍然可用，不需要装进系统字体库。
- **颜色**：点颜色方块会打开完整调色板，可以选择色相、明暗、透明度和常用颜色，预览会实时更新；也可以直接输入十六进制颜色值。
- **清晰度**：流畅、高清、超清三档决定渲染尺寸。清晰度旁边会显示当前导出尺寸，例如 `226×122 · 1 行 · 20 字/行`。

预览显示的是字幕在整帧画面里的位置；导出的叠加视频会按字幕内容裁掉四周空白，所以比原视频小很多。每条音轨可能得到不同尺寸的叠加视频。

## 导出

在预览面板里点「导出」：

| 格式 | 用途 |
|---|---|
| WebM (VP9) | 带透明字幕层的叠加视频，适合大多数剪辑软件。 |
| MOV (ProRes 4444) | 带透明字幕层的叠加视频，适合专业剪辑软件。 |
| MP4 (H.264) | 普通视频，不支持透明。 |
| SRT / ASS / VTT | 字幕文件，方便播放器或其他剪辑软件使用。 |

- 导出叠加视频时，每条勾选且有字幕的音轨会生成一个文件。
- 鼠标移到音轨行上，点出现的音频导出按钮，可以把这条音轨单独导出成 `.m4a`。
- 导出使用原视频的帧率。
- 导出失败时，窗口左下角会出现红色提示；鼠标悬停可以展开完整内容，点击可以复制。

## 设置

从模型菜单打开「设置」。

- **提供商**：左侧列出本地和云端识别服务。整行都可点击，点哪行就编辑哪家。「添加模型提供商」可以接入 OpenAI 兼容服务。「连接测试」会检查 Key 和地址，并更新可用模型。
- **本地模型**：下载、继续、停止或删除模型。
- **识别前降噪**：开启或关闭降噪。
- 关闭设置窗口时自动保存，没有「取消」按钮。
- 窗口位置、大小和面板布局会自动记住。

> **API Key 以明文保存在本机。** 能读取你用户目录的人或程序都能看到它。公共电脑上请谨慎使用；如果怀疑泄露，请尽快到服务商平台吊销并重新生成。

## 语言

用底栏的语言菜单在简体中文和 English 之间切换，立即生效，不需要重启。「更多语言…」会重新打开语言选择窗。

第一次启动时软件会让你选择语言，之后会记住你的选择。

## 遇到问题时

- **操作失败**：左下角的红色提示会显示错误的前半段，鼠标悬停展开全文，点击复制。
- **程序意外退出**：详细信息会写入用户设置目录里的 `crash.log`，反馈问题时可以附上。
- **无法保存设置或导出**：如果是权限原因，软件会提供「以管理员重启」。
- **SmartScreen 提示**：安装包没有签名，点「更多信息 → 仍要运行」即可。
- **软件提示缺少 ffmpeg**：用弹窗里的下载链接下载，把文件放进弹窗显示的文件夹（或把 ffmpeg 加进 PATH），然后点「重新检测」。
- **MP4 没有透明效果**：MP4/H.264 不支持透明通道，请改用 WebM 或 MOV。

## 已知限制

- MP4 导出不支持透明，叠加字幕请用 WebM 或 MOV。
- 云端识别需要 API Key；离线识别需要先下载本地模型。
- 长视频按音轨依次处理。可以随时停止，但停止后的音轨需要从头重新识别。
- 超长素材的预览播放只处理前 30 分钟。
- 如设置中所述，API Key 以明文保存。
